⚙️ للمطوّرين: أهم الأبواب

POST/explanations/generateابعت الجراف ← بيعمل الشرح ويحفظه، وبيرجّع رابط الصفحة والهوية.
GET/explain/{book_id}الصفحة التفاعلية لكتاب (نفس المنشورة). /explain = كل الكتب.
GET/explain-dataالداتا (JSON) لأي فرونت إند بده يرسم بطريقته.
GET/booksالكتب على السيرفر · /books/{id}/lessons دروس كتاب.
GET/art/{key}.svgرسمة شخصية كـ SVG (نفس رسومات الصفحة، والليغو).
DELETE/books/{book_id}احذف كتاب.
GET/healthهل السيرفر شغّال، ونسخته.

مثال (من الطرفية):

curl -X POST {ORIGIN}/explanations/generate \
  -H "Content-Type: application/json" \
  -d '{"graph": { ...الجراف... }, "use_llm": false}'
